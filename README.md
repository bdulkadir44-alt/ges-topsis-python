# ges-topsis-python

Bu depo, "Güneş Enerji Santrali (GES) Arazi Seçiminde Python Tabanlı TOPSIS
Uygulaması: Yönetim ve Sürdürülebilir Pazarlama Açısından Bir Değerlendirme"
başlıklı makalenin analiz kodunu içerir.

Kod, makaledeki Tablo 1 ve Tablo 2'deki verilerle TOPSIS yöntemini uygular
(Formül 1-11), sonuçları makaledeki değerlerle karşılaştırır ve Şekil 1'i üretir.

## Gereksinimler
Python 3.9 veya üzeri; numpy, pandas, matplotlib

## Kurulum ve çalıştırma
pip install numpy pandas matplotlib
python ges_topsis.py
